1>Create a dot env file under folder, and put all APIs key of LLMs.
2>Create a virtual env as well.
3>Why Langchain needed? -- Suppose we building GenAI appl and need multi model LLMs like from OpenAI,
Claude, Gemini etc.. so every LLMs API work differently and syntax also diff.So Langchain framework
unites all at a place and easy to deliver tasks.
4>To activate venv -- python -m venv env {to create}
                    . env/bin/activate {to activate}
5>docs.langchain.com - powerful page with max information.

6>LangChain organizes components into these main categories:	
    Models	
    Tools	
    Agents	
    Memory	
    Retrievers	
    Document processing	
    Vector Stores
